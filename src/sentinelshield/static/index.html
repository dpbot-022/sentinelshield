Autonomous Self-Healing JSON Repair Loop

When Open LLMs produce invalid types, missing fields, or broken markdown fences, traditional applications crash with 500 Internal Server Errors. SentinelShield intercepts the Rust-backed ValidationError in memory, generates a precision schema error diff, and re-prompts the model for an instantaneous correction before returning to the client.
