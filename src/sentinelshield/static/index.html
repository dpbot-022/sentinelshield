Sub-100ms Self-Healing JSON Repair Loop

When open models (such as phi3:mini, qwen2.5:1.5b, or llama3.2:3b) produce markdown wrappers, drop required fields, or output invalid types, standard applications crash. SentinelShield intercepts the Rust-backed ValidationError in memory, generates a targeted diagnostic diff, and re-prompts the model for an instantaneous sub-100ms correction.
